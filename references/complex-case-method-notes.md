# 复杂盘案例复核方法

来源线索：公开案例复核与复杂盘分析方法。本文件只提炼方法，不复制原文。

## 适用场景

用于处理：

- 名人案例、公开案例或现成分析文本
- 用神争议明显的命盘
- 三会、三合、合绊、冲库、四支同向等结构复杂的命盘
- 用户要求比较书房派、盲派、梁派、旺衰病药等不同路数

## 方法一：先复核结构，再谈用神

复杂盘不能只按“月令得令”直接定身强身弱。必须继续看：

1. 地支是否成三会、三合或半合，导致五行气势改道。
2. 天干关键星是否被合住，导致透出但力量受限。
3. 日支、月支、年支是否有冲库，导致库中之气被打开。
4. 根气被合、冲、会之后，日主是真强、假强、真弱，还是局势压过普通旺衰。

结论格式：

```md
表面看：……
但结构复核后：……
所以不能直接按：……
更稳的判断是：……
```

## 方法二：用神必须分层

不要把“有用”“成名”“能赚钱”“能表达”全部叫用神。至少分四层：

1. 调候用神：解决寒暖燥湿。
2. 扶抑/病药用神：解决身强身弱和结构病处。
3. 成事工具：让才华、表达、职位、财源落地。
4. 应期触发器：某步运或某一年把事件引出来。

同一颗星可能是成事工具，但不是调候或病药核心；也可能在事业上有用，在婚姻、子女、健康上形成代价。

## 方法三：区分输出和源头

食伤代表输出、表达、才华、课程、作品、技术方案。它能让人被看见，但不一定能让人持续稳定输出。

判断时要追问：

- 谁在供给食伤：印、比劫、调候，还是大运临时托底？
- 食伤带来的是长期稳定收益，还是短期传播、人设反差、局部破圈？
- 食伤是否同时带来破财、关系损耗、组织冲突或健康耗泄？

## 方法四：多门派视角要分层，不要硬拼

同一个盘可以用多种视角观察，但必须说明各自解决的问题：

- 子平主线：月令、旺衰、格局、调候、病药、用神。
- 象法/盲派视角：抓最响的冲合、库、宫位和现实象。
- 气势视角：看全局气往哪里走，源头在哪里，是否流通。
- 年表反证：看关键岁运是否支持某套判断。

不要把不同体系硬拧成一个“唯一标准答案”。更稳的写法是：

```md
这套说法在 A 层成立，但到 B 层解释力不足。
另一套说法在术语上不一定更漂亮，但能连续解释关键年表，所以权重更高。
```

## 方法五：用现实年表反证，而不是事后硬套

如果某套说法主张某五行/十神为用，就要看：

1. 该五行/十神旺的大运是否真是核心上升期。
2. 关键学历、职位、出圈、财务、婚姻、健康节点是否能被连续解释。
3. 另一套假说是否能更自然地解释同一组节点。
4. 如果只解释了局部特征，要降级为“局部成事工具”。

年表反证不是为了神断某一年，而是为了判断哪套结构假说解释力更强。

## 方法六：职业分析拆成四件事

复杂职业盘尤其要拆开：

- 被看见靠什么：食伤、比劫、作品、表达、技术。
- 被平台放大靠什么：印、官、年柱、月柱、组织背书。
- 变现靠什么：财星、项目、薪俸、资源流动。
- 代价在哪里：耗身、破财、婚姻波动、子女耗费、健康透支、组织摩擦。

因此，不能因为表达强就直接建议自由职业或内容赛道；也不能因为在大单位就忽略食伤带来的传播力。
