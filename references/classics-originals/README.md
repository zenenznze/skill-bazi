## 使用规则

1. 本地检索优先用 `rg "关键词" references/classics-originals/raw`。
2. 引用时注明书名和本地文件；关键结论最好回源页面复核。
3. 不把本地文本当成唯一底本。若不同来源有异文，必须说明采用哪个来源。
4. 本目录不提供译文；分析输出如需解释，另在回答中做现代语言转写。
