# 八字分析总控与输出规范

## 目标

把八字分析过程中的通用方法论、输出顺序、证据规范、语言风格、验盘逻辑，固化成一个总控模块，供其他子模块调用。

这个模块不直接替代细分模块，而是负责：

1. 统一分析流程
2. 统一表达标准
3. 统一证据与校验习惯

## 适用场景

- 需要把多个子模块串成完整分析链
- 存在出生时间、换日、候选盘争议，需要先定盘再落专题
- 需要形成长期可复用的八字分析 SOP

如果用户已经默认接受现成命盘，或者问题只是单一专题，不必为了形式完整而强行重走全部链路。

## 总原则

### 原则 1：完整链路问题先定盘，再论命，再验事，再落建议

当问题涉及出生信息争议、候选盘、换日、真太阳时时，标准顺序不可乱：

1. 排盘与换日校验
2. 候选盘差异说明
3. 前事反推验盘
4. 正式采用命盘
5. 主题分析，如职业、婚姻、家庭
6. 流年或大运验证
7. 现实建议

### 原则 2：命理结论必须结构加现实事件双落地

不要只说：

- 官杀旺
- 财星动
- 食伤透

必须同时翻译成现实：

- 压力结构
- 家庭感受
- 学习方式
- 恋爱模式
- 职业环境
- 时间节点事件

### 原则 3：用户长期要求书证时，要附专业命理依据

根据既有要求：

- 凡谈八字或命理，尽量沿用最近一次分析脉络
- 尽量附专业命理书籍原文依据
- 把命理结构与现实中的具体事件做对应分析，而不是只做抽象判断

书证的用途不是炫技，而是让结论有体系来源。

### 原则 4：理论分歧要透明，不偷换前提

涉及以下问题时，必须说明当前采用哪套规则，以及不采用另一套规则的原因：

- 真太阳时
- 子时换日
- 节气切月
- 顺逆行运

### 原则 5：优先比较解释力，不追求绝对化神断

命理分析最稳的方式是：

1. 建立候选
2. 对照现实
3. 选择解释力更强者

### 原则 6：先分清“验盘题”还是“结构题”

这两类问题不能混答：

- 验盘题：问“哪张更像这个人本人”
- 结构题：问“哪张格局层次更高、结构更清、原局更完整”

如果用户问的是验盘题，就不要把“格局层次更高”偷带进去。
如果用户问的是结构题，就不要把“他本人反馈哪张更准”混进去。

### 原则 7：复杂盘先做结构复核，再谈用神

遇到三会、三合、合绊、冲库、全局气势明显偏移的盘，不可只凭月令或单一旺衰口诀定用神。

必须先回答：

- 月令之气有没有被会局、合局、冲库改变走向
- 天干关键星是否被合住、合绊、透而不透
- 地支根气是否被冲开、合走、引动
- 所谓“用神”是在调候、扶抑、成事、应期中的哪一层
- 现实年表是否支持这个用神判断

## 统一分析流程

### Phase 1：输入校验

检查是否具备：

- 出生年月日时
- 性别
- 出生地
- 需要解决的问题
- 是否存在候选盘或争议点

若缺出生地，而时间又接近时辰边界，必须提醒这会影响真太阳时判断。

### Phase 2：排盘

调用 `modules/chart-calibration/`，输出：

- 标准盘
- 真太阳时盘
- 候选盘
- 正式采用盘，暂定

### Phase 3：验盘

调用 `modules/retro-validation/`，优先验证：

- 人格底色
- 家庭与父母气质
- 学历与专业
- 恋爱模式
- 关键年份

如果现实信息不足，需要先向当事人提问，必须遵守 `references/momtest-validation-questions.md`：问过去具体事实、年份、原话和可佐证记录，不把候选盘画像、命理术语或“你是不是……”式判断提前喂给对方。

### Phase 3.5：复杂结构复核

当原局存在强三会/三合、明显合绊、冲库、四支同向、调候与扶抑矛盾时，正式落专题前先复核：

- 结构主轴：全局气往哪里走，不只看月令表面
- 调候需求：寒暖燥湿最先需要什么
- 病药关系：最大的病处是什么，药是否真的能到位
- 用神分层：调候用神、扶抑用神、成事工具、岁运触发器是否混同
- 现实反证：关键大运和流年是否支持初始判断

### Phase 4：专题分析

根据用户问题进入：

- 年份验盘：`modules/year-timeline-validation/`
- 职业：`modules/career-direction/`
- 婚恋、健康、现实困惑：`modules/bazi-analysis/`
- 未来若继续扩展，可补家庭、流年等专题

### Phase 5：收口

最终输出需明确：

1. 当前采用哪张盘
2. 为什么采用
3. 结论置信度在哪里高、哪里低
4. 后续还可用哪些现实信息再校验

## 统一输出结构

推荐顺序：

### 1）先给结论

开头就回答用户最关心的问题，例如先取哪一盘、哪类职业路径更合适、哪类平台更优先。

### 2）再给依据

依据顺序：

- 节气或排盘依据
- 十神、格局、旺衰依据
- 书证依据
- 现实对应依据

### 3）再翻译成现实语言

术语后必须翻译成人话。

### 4）最后给核验点或行动建议

例如让用户核哪五条，或给职业选择优先级、下一步补充材料。

### 5）比较类问题先标明比较维度

如果在比较两张或多张盘，开头必须先声明这次比的是哪一类：

- 前事解释力
- 年份应事能力
- 原局格局层次
- 职业平台适配

避免把多个维度混成一句结论。

## 统一证据规范

### 书证使用规范

优先使用：

- 《滴天髓》
- 《穷通宝鉴》
- 《渊海子平》
- 《三命通会》

书证引用规则：

1. 只引用真正服务于当前结论的句子
2. 引文后要翻译，不要只堆原文
3. 不能用书证替代现实校验
4. 若理论存在分歧，要明确采用何种取法

### 现实校验规范

至少选择以下之一落地：

- 学历或专业
- 家庭气质
- 感情模式
- 关键年份
- 职业选择

命理结构必须和至少一个现实层面对应。

现实校验分两步：提问阶段只采集事实，分析阶段再把事实映射到命理结构。不得为了验证结论而问“某年是不是发生某事”“你是不是某种性格”“你更像哪张盘”。

### 用神分层规范

输出用神时必须避免一句“某字为用”包打天下。复杂盘至少分清：

1. 调候层：这个盘先要暖、润、通、燥、泄，还是制。
2. 扶抑层：日主真实状态是偏强、偏弱、假强、假弱，还是局势压过旺衰。
3. 成事层：哪颗十神让学历、职位、表达、交易、名声真正落地。
4. 代价层：同一颗星在哪些领域有用，在哪些领域反而形成消耗。
5. 应期层：哪步大运、哪一年把这个结构引出来。

如果几层不是同一个字，要明确说明“它有用，但不是同一层面的用神”。

## 语言风格规范

### 应该这样写

- 先给结论，再展开
- 术语翻译成人话
- 有差异化画像
- 敢于排序、敢于取舍
- 说明边界和置信度

### 不应该这样写

- 通篇术语堆砌
- 每种可能都说一点，最后没有判断
- 说得玄但不能对应现实
- 该有争议的地方装成没有争议
- 书证乱贴，不解释
- 用户问“哪个层次更高”，却回答成“哪个更像他本人”
- 用户问“哪个更像本人”，却偷换成“哪个格局更清”

## 高复用不变规律

### 规律 1：排盘正确性高于一切神断

盘没定好，后面越分析越错。

### 规律 2：争议案例必须候选盘加验盘双步骤

直接站队容易错；先列候选，再用前事压缩范围更稳。

### 规律 3：人物底色比单一年份更稳定

人格、家庭感受、恋爱模式通常比某个年份的一件小事更有验盘价值。

但向当事人采集信息时，不能直接问“你是不是这种人格/家庭/恋爱模式”。要问具体经历，再由分析者后台判断底色。

### 规律 4：职业建议必须落到平台乘岗位乘行业三维

只说行业名词，几乎没有可执行性。

### 规律 5：命理分析的价值不在玄，而在帮助决策

最终目标不是让用户感叹神奇，而是帮助用户认盘、验盘、选方向、避坑。

### 规律 6：年份验盘适合做最后一刀

当底色层和结构层已经缩小范围，但仍然分不出胜负时，用年份和事件类型来做最后区分，效率最高。

### 规律 7：现实履历可以反证用神，不只是验证时辰

名人案例或已有年表的命盘，不只用年份验“哪张盘像”，也可以验“哪套用神解释更稳”。

重点看：

- 被主张为用神的五行/十神旺时，是否真出现核心上升或长期受益
- 另一套假说对应的岁运，是否更能解释学历、职位、出圈、财务、婚姻、健康等节点
- 若某星只解释了才华或人设，却解释不了平台、名位和关键上升期，不可直接定为全局用神
