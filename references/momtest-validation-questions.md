# Mom Test 式验盘提问规范

## 来源

本规范来自 Mom Test 式事实访谈方法，重点参考：

- The Mom Test 间接调研方法论笔记。
- “问生活，不问意见”的概念素材笔记。

这里不照搬原文，只把方法改造成八字定盘、子时验盘和前事反推可用的提问纪律。

## 核心原则

### 1. 问生活，不问命理判断

不要让对方评价候选盘、性格画像或命理假设。对方一旦知道你想验证什么，就容易进入配合、迎合、反驳或自我解释模式。

正确做法是让对方描述真实发生过的事：

- 什么时候。
- 谁在场。
- 当时发生了什么。
- 对方原话或大概原话是什么。
- 后来怎么处理。
- 结果持续了多久。
- 有没有记录能佐证。

### 2. 问过去的具体事实，不问未来和笼统感受

不要问“你以后会不会”“你觉得自己是不是”“你像不像”。这些回答不稳定，也容易被问题暗示。

优先问：

- 最近一次。
- 印象最深的一次。
- 某个年份实际发生了什么。
- 当时做了什么，而不是怎么看自己。

### 3. 先收集，再评分

验盘时可以在分析者内部比较候选盘，但提问阶段不要泄露候选差异。

流程是：

1. 先用中性问题采集事实。
2. 再把事实映射到候选盘的解释力。
3. 最后才给出哪张盘加分、哪张盘减分。

## 八字验盘里的问题转换

| 想知道 | 不要这样问 | 应该这样问 |
|---|---|---|
| 父母谁更强势 | 你爸是不是比较强？你妈是不是更操心？ | 小学到高中阶段，家里遇到升学、搬家、花钱、管成绩这类决定时，印象最深的一次是谁先提的？谁最后拍板？当时怎么说的？ |
| 家庭氛围松紧 | 你家是不是管得很严？ | 小时候有没有一件因为作业、成绩、作息、花钱或交朋友被家里管得很具体的事？当时具体怎么管，后来结果怎样？ |
| 学业走势 | 你是不是有能力但发挥波动？ | 从小学到现在，成绩、学校、专业或方向变化最明显的一次是哪一年？变化前后发生了什么？ |
| 压力反应 | 你是不是很能忍、很能扛？ | 最近一次遇到考试、工作、家庭或关系压力时，你具体做了哪些事？有没有找人、拖延、硬撑、争辩、逃开或重新安排？ |
| 职业倾向 | 你适合体制还是技术？ | 过去做过的学习、工作或项目里，哪件事最耗时？具体任务是什么，谁给你的，最后怎么交付？ |
| 恋爱模式 | 你是不是容易上头拉扯？ | 第一段或影响最大的一段关系是什么时候开始的？怎么认识、怎么推进、期间发生过什么具体转折，最后怎么变化？ |
| 年份应事 | 2016 年是不是有冲突？2022 年是不是换方向？ | 下面年份不代表一定有事。如果有升学、搬家、关系变化、家庭变化、身体状态变化、工作转向，就写具体经过；没有就写无。 |

## 标准开场

> 我们先不判断你是什么性格，也不让你配合任何结论。我只是帮你整理一份事实时间线，用来核对出生时间边界。你尽量说真实发生过的事：时间、地点、谁在场、发生了什么、后来怎么处理。如果某一年没事，直接说无。

## 标准问题清单

### 出生时间证据

1. 这个出生时间是从哪里来的？出生证明、医院记录、户口材料、家人口述，还是后来听说的？
2. 家里有没有人对出生时间有过不同说法？原话大概怎么说，比如“晚上”“快 23 点”“夜里”“吃完饭后”。
3. 有没有可能是四舍五入、记错日期、夏令时、地方时间、医院或家里钟表本身不准，或后来补登记？

### 开放事实

1. 从小学到现在，你最记得清楚的 5 个年份或年龄段是什么？每个年份发生了什么？
2. 小学、初中、高中、大学或工作阶段，有没有换学校、搬家、换城市、休学、转专业、换方向？分别是哪一年？
3. 家里做重大决定时，印象最深的一次是什么？谁先提出来，谁反对，谁最后拍板？
4. 你和父母或长辈在升学、花钱、作息、交友、搬家等事情上，印象最深的一次沟通是什么？当时各自怎么说，后来怎么收场？
5. 学业上最明显的一次上升或下滑发生在什么时候？当时老师、家庭、身体或环境有什么变化？
6. 过去有没有某一年身体、睡眠、情绪或精力状态和前后明显不一样？那一年具体发生了什么？
7. 第一段或影响最大的关系发生在什么时候？怎么开始，期间有什么转折，后来怎么变化？
8. 有没有哪一年你明显换了一种圈子、生活方式、目标或工作方向？那一年实际发生了什么？

## 追问模板

- 当时具体发生了什么？
- 这件事是谁先提出来的？
- 对方原话或大概原话是什么？
- 你当时做了什么，不是怎么想？
- 后来结果是什么？
- 这件事影响了多久？
- 有没有成绩、证书、医院记录、聊天记录、搬家记录、入学或工作时间可以佐证？

## 禁止问法

- 不问“你是不是某种性格”。
- 不问“你更像 A 盘还是 B 盘”。
- 不问“某年是不是发生了某类事”。
- 不把候选盘的画像、十神、格局、喜忌讲给当事人后再让对方反馈。
- 不用吓人结论推动对方回忆，比如婚姻、子女、健康灾祸等。

## 输出要求

生成待核问题时，必须把问题写成事实采集表，而不是命理判断题。

分析返回答案时，再使用命理语言评分：

- 哪些事实支持 A 候选。
- 哪些事实支持 B 候选。
- 哪些事实无法区分。
- 哪些关键事实还缺失。

如果事实不足，不硬选盘。
