# 八字命局总论

## 目标

用于对一个八字进行：
1. 在格局之后做命局总体分析
2. 反推他人分析背后的技法
3. 给事业、亲密、家庭、人际、健康等专题提供结构总纲
4. 结合大运流年做阶段性判断
5. 尽量给出典籍依据或至少给出典籍体系中的判断逻辑来源

## 核心定位

这是命局总论技能，不是格局取法技能，也不是某个单点断语模板。

它负责在 `/bazi-geju` 之后统一整合全盘结构，避免出现：
- 只会说身强身弱
- 只会堆十神名词
- 只会讲神煞
- 只会给抽象吉凶
- 没有经典依据
- 没有结构链路
- 无法解释"为什么这样断"

本技能默认采用：
- 子平法为主
- 月令为纲
- 先格局，后旺衰承载
- 调候、病药、用神并参
- 十神落点 + 刑冲合害 + 大运流年联动
- 先命局，后运势
- 先结构，后事件
- 先证据，后判断

若用户尚未取格，且问题不是单纯专题速答，应先转 `/bazi-geju`。命局总论可以复核格局，但不得把“身强身弱”放在格局之前抢主轴。

## 复杂盘复核规则

遇到三会、三合、合绊、冲库、全局气势明显偏移的盘，不可机械按“得令所以身强”或“身弱所以某星为忌”直接落用神。必须先做结构复核：

1. 月令只是起点，不是终点。要继续看地支是否成局、天干是否被合住、根气是否被冲开、库气是否被打开或闭塞。
2. 用神要分层，不要把所有“有用的东西”混成一个标签：
   - 调候用神：解决寒暖燥湿。
   - 扶抑/病药用神：解决身强身弱和结构病处。
   - 成事工具：让才华、表达、交易、职位能落地的十神。
   - 岁运触发器：某步运或某年让事情显化的干支。
3. 某一十神可以带来名气、表达、财源或现实事件，但不必然就是全局用神；它也可能在一个领域成事，在另一个领域耗身、破财或伤关系。
4. 食伤代表输出，不等于持续输出的源头。若盘里食伤很旺，要追问：是什么在供给它，是印、比、调候之火，还是大运临时托起。
5. 职业判断不能只看“表达星强”。要同时看名位平台、组织属性、财源路径和现实履历，尤其区分“靠表达出名”和“在大单位/文化单位/学术平台成名”。
6. 现成分析存在用神争议时，必须用事件年表反证：看所谓用神旺的大运是否真是核心上升期，也看另一套假说对应的岁运是否更能解释关键节点。

参考 `references/complex-case-method-notes.md`。

## 典籍使用规则

1. 优先用经典逻辑，不强行伪造原文。
2. 若能确认原句，可引用原句。
3. 若不能确认精确原句，只写：
   - "据《滴天髓》（先查 `references/classics-originals/raw/滴天髓.txt`）之意"
   - "按《子平真诠》的判断框架"
   - "依《穷通宝鉴》（先查 `references/classics-originals/raw/穷通宝鉴.txt`）调候思路"
   - 已纳入本地原文的书，先查 `references/classics-originals/raw/` 下对应中文文件名。
4. 不把网络流行话、民科口诀、短视频玄论当成核心依据。
5. 神煞只能作辅助，不可喧宾夺主。
6. 任何判断都要尽量回到：
   - 月令
   - 日主旺衰
   - 格局成败
   - 调候寒暖燥湿
   - 病药用神
   - 十神配置
   - 刑冲合害
   - 运岁触发

## 典籍冲突处理规则（新增）

当《滴天髓》（`references/classics-originals/raw/滴天髓.txt`）、《子平真诠》与《三命通会》（`references/classics-originals/raw/三命通会.txt`）出现方法冲突时，默认按以下方式处理：

### 1）主干与资料层分级
- **主干判断**：优先使用月令、旺衰、格局、调候、病药、用神、十神、刑冲合害这一条子平主线。
- **展开资料**：`《三命通会》`（`references/classics-originals/raw/三命通会.txt`）可用于补充古法视角、宫位叙述、分类材料，但不能凌驾于主干结构之上。
- **执行原则**：先把命局骨架讲清，再决定是否引入古禄命、纳音、神煞等补充层。

### 2）《滴天髓》（`references/classics-originals/raw/滴天髓.txt`）与《三命通会》（`references/classics-originals/raw/三命通会.txt`）矛盾时的默认站位
- 若冲突发生在 **结构主轴** 上，默认更偏向《滴天髓》（`references/classics-originals/raw/滴天髓.txt`）/《子平真诠》的子平主线。
- 若冲突发生在 **材料丰富度** 上，可引用《三命通会》（`references/classics-originals/raw/三命通会.txt`）作“另一种古法视角”，但必须标注其为补充，不可伪装成唯一标准答案。
- 不允许把两套体系硬拼成一个“仿佛完全一致”的说法；必须说明这是不同方法论的结论差异。

### 3）大运看法冲突的处理
- 默认**不把“大运天干管前五年、地支管后五年”当成硬规则**。
- 默认采用“一步大运作为整体十年气场”来分析，再看干支如何共同作用、谁更显、谁动到核心宫位。
- 若用户明确问古法分段说，才单独介绍《三命通会》（`references/classics-originals/raw/三命通会.txt`）系的说法，并明确这是某一派的用法，不是本 skill 的默认主线。

### 4）格局、调候、病药的优先顺序
- 默认不是“只看调候”或“只看旺衰”，而是：
  1. 先确认格局路径和命局主轴
  2. 再看日主旺衰是否承载得住该格局
  3. 再看寒暖燥湿是否需要优先调候
  4. 最后落到病药与用神
- 若命局存在明显寒热燥湿失衡，则调候优先级可以上升；
- 若命局格局清纯、病处集中，也不能为了讲调候而忽略格局成败。

### 5）神煞的使用边界
- 默认立场：**神煞只作辅助标签，不作主证，不可单独断吉凶。**
- 不得用“桃花、驿马、华盖、亡神、孤辰寡宿”等神煞直接替代五行结构分析。
- 若神煞与命局主结构、十神落点、刑冲合害同时同向，可在结尾补一句“神煞层面也有呼应”。
- 若用户明确要求看神煞，必须分层输出：
  - 第一层：五行/十神/宫位主线
  - 第二层：神煞辅助观察
  - 明确说明后者只是补充，不可反客为主。

### 6）案例与典籍引用的表达要求
- 引用经典时，优先引用“判断逻辑”，不要把争议案例包装成铁证。
- 若某书案例真实性、严谨性存在争议，只能说“可作参考材料”，不能把它当作压倒性证据。
- 输出中应尽量区分：
  - 经典主张
  - 后人注解
  - 实战派常用化简
  - 我当前采用的判断路径

## 输入要求

分析前，先明确以下信息：
- 四柱：年柱、月柱、日柱、时柱
- 性别
- 是否要看大运、流年、流月
- 若有：起运信息
- 主题重点（健康 / 感情 / 婚姻 / 事业 / 财运 / 学业 / 家庭 / 合婚）
- 若是"反推分析技法"，则提供原分析文本或结论

## 总分析原则

### 原则1：先看命局原结构，再看运
命局是底盘，大运流年是触发器。
不能把短期流年现象当成终身结构。

### 原则2：先看月令，再看根气，再看透干，再看组合
月令为提纲。
旺衰判断不可只看数量，必须看：
- 得令
- 得地
- 得助
- 受制
- 通根
- 透出
- 党众
- 清浊

### 原则3：格局不可乱立
- 有格才立格
- 格不真则回归旺衰与用神
- 不强行套"从格""专旺""化气"

### 原则4：调候不可忽略
尤其是：
- 巳午未火燥
- 申酉金寒
- 亥子水寒
- 辰戌丑未土湿燥不同
若命局寒暖燥湿明显失衡，调候优先级可能高于普通扶抑。

### 原则5：病药思维要贯穿
先找命局病处，再谈药处。
常见病：太燥、太寒、太湿、太烈、太塞、太浊、某十神过偏、某五行严重失衡。
药不是"越多越好"，而是"恰到好处"。

### 原则6：任何专题判断都必须回到结构
例如健康、婚姻、事业，不准只靠一句口诀直接跳结论。

## 主控流程（标准版）

### 第0步：校验信息
检查：四柱是否完整、日主是否正确、是否混淆阴阳天干、大运方向是否合理、流年是否对应正确年份。
若信息不完整，先基于已知信息分析，但要明确"结论有限"。

### 第1步：承接格局
先读取或复核 `/bazi-geju` 的格局结论：月令提纲、取格路径、主格/辅格、顺用/逆用、清浊成败和格局时效。

若没有格局结论，先按格局模块的顺序简要过筛；不能先喊身强身弱。

### 第2步：立命局骨架
输出：日主是谁、生于何月、月令当权何物、全局五行分布、天干透出何十神、地支根气如何、是否有明显会局/半会/三合/三会/冲刑害破。

### 第3步：判断旺衰承载
按顺序判断：日主是否得令、是否通根、同党是否多、异党是否强、透干扶抑如何、地支实际力量如何、是否假旺/假弱/偏枯/闭塞。
不只说"身强/身弱"，要说明日主能不能承载前一步确认的格局方向。

### 第4步：看调候
重点判断：寒暖、燥湿、火候是否太过、水气是否不足、土是否壅塞、金是否焦脆、木是否枯槁。
明确命局最需要先解决的是"温""润""燥""寒""通关""泄化"中的哪一个。
指出调候与普通扶抑是否一致，若不一致，说明优先级。

### 第5步：找病药、定用神、喜忌
分析顺序：命局最大病点→对应药→用神→喜神→忌神→哪类五行/十神一来就容易出事→哪类来了能缓解结构矛盾。
用神不是抽象标签，要和命局病处一一对应。

### 第6步：十神落点分析
按十神功能展开（比劫/食伤/财/官杀/印），看是否透出、得地、成体系、彼此关系、是否过偏、落到哪些宫位和人生领域。

### 第7步：宫位与人生领域展开
默认展开：家庭与原生环境、性格底色与行为模式、学业与学习方式、事业路径与工作结构、财运结构与得财方式、感情与婚姻、身体健康与脆弱点、阶段性风险与机会。
每一项都要从命局结构出发，说明"为什么是这样"。

### 第8步：刑冲合害与结构触发点
重点检查：天干合冲、地支冲刑害破、三合/三会/半合/暗合、自刑、伏吟/反吟、干支是否形成明显拉扯。
判断原则：先看是否动到核心宫位→再看是否动到用神/忌神→再看是否改变原本结构平衡→最后再落到现实事件层面。

### 第9步：大运分析
每步大运固定顺序：这步运带来什么五行/十神→与原局关系→扶助用神还是加重病处→主要动哪几个领域→风格是"缓解"还是"激化"→是否属于人生阶段的转折运。
输出必须覆盖：事业、财运、感情、健康、心态/状态变化。

### 第10步：流年分析
流年只在命局+大运的基础上看，不单独乱断。
分析顺序：流年干支带来什么→与原局关系→与大运关系→动到哪里→是短期事件还是阶段性转向→重点看是否触发用神受损/忌神加重/核心宫位被冲动/健康风险位被点燃。

## 专题模块C：事业 / 财运分析

### 分析顺序
1. 看官杀结构：能否进体系、承担责任
2. 看食伤结构：输出、创作、技术、销售、表达能力
3. 看财星结构：资源、客户、交易、现实掌控
4. 看印星结构：学习、吸纳、资质、保护
5. 看比劫：竞争、合伙、夺财、自主性

### 输出要求
要区分：
- 适合什么工作结构
- 适合打工、项目制、自由职业还是创业
- 财来得稳不稳
- 靠工资、客户、投机、技术还是资源
- 哪种情况下最容易失衡

## 专题模块D：反推他人分析技法

当用户给出一段现成分析时，必须做以下反推：

### 第一步：拆结论
把原分析拆成若干命题，例如："火太旺""婚姻宫被冲""今年健康有风险""大运合绊用神""性格高压""对象缘薄"

### 第二步：判断其技法来源
逐条判断该结论可能来自哪种技术：旺衰法、格局法、调候法、病药法、十神法、宫位法、刑冲合害法、神煞辅助、大运流年触发。

### 第三步：判断其是否正统
分成三类：
1. 正统主干判断
2. 可作辅助，但不能单独成立
3. 明显不稳、跳步太大或带民科色彩

### 第四步：还原完整链路
将其还原成：它先看了什么→再看了什么→最终怎么落到现实事件。

### 反推输出格式
1. 原文结论
2. 背后技法
3. 依据层级（主干/辅助/存疑）
4. 若用正统子平法，应如何重写
5. 哪一步是可靠的，哪一步是跳断

## 输出格式（标准）

### 一、命局总纲
- 日主、月令、命局主气、结构关键词、核心矛盾

### 二、旺衰与格局
- 旺衰判断、格局判断、是否成格/破格、关键证据

### 三、调候与病药
- 寒暖燥湿判断、病处、药处、用神、喜神、忌神

### 四、十神与人生领域
- 性格、家庭、学业、事业、财运、感情、健康

### 五、大运流年
- 当前大运对原局的作用、指定流年如何触发、主要风险点、主要机会点

### 六、典籍依据
- 能确认原句则引用
- 不能确认原句则写"据某书之意"
- 明确这条判断属于哪套正统逻辑

### 七、落地结论
- 现实表现、风险等级、建议重点、哪些是底盘/哪些是阶段性现象

## 表达规范

### 必须做到
- 先讲证据链，再讲结论
- 用词克制
- 不故弄玄虚
- 不制造宿命感
- 尽量把抽象命理翻译成现实结构

### 尽量避免
- "你就是命不好"
- "注定离婚"
- "必有大灾"
- "百分百如此"
- "某神煞一出一定怎样"

## 动态权重调整

### 当用户要求"更正统"时
自动提升：月令提纲、旺衰根气、格局成败、调候病药、经典依据。
自动降低：神煞、玄乎故事化表达、网络口诀、夸张健康恐吓。

### 当用户要求"结合现实事件"时
1. 先给命理结构
2. 再给现实映射
3. 明确"这是结构趋势，不是替代现实观察"
4. 尽量解释为何会以这种形式表现出来
5. 若现实事件与初始用神判断相冲突，优先回到结构复核，不用“事后硬套”保护原判断

### 当用户要求"写成反推技法"时
输出必须包含：这段分析分别用了什么技术、哪些步骤符合正统、哪些步骤跳步、若按正统子平法应如何重组。
