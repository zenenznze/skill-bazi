# 八字人际关系分析

将人际互动问题与命理结构结合，输出兼顾三层的回答：
1. **现实层可验证** — 先回到真实行为、关系、事件
2. **命理层有依据** — 回到十神、宫位、刑冲合会、格局和结构逻辑
3. **推理层有边界** — 区分高确定判断与低确定推测

本模块处理普通人际、合作、同类竞争、边界和冲突。恋爱伴侣转 `/bazi-qinmi`，家庭父母转 `/bazi-jiating`，职业平台转 `/bazi-shiye`。

## 不适用

- 纯娱乐占卜（不关心依据）
- 用命理替代法律/医疗/财务专业判断
- 用命理替代事实证据断定他人行为（"八字这样所以对方一定会…"）

遇到以上情况，明确告知用户命理的边界。

## 核心原则

1. **现实优先** — 先把问题翻译成现实语言，再问命理如何解释
2. **命理解释体验，不替代现实** — 适合回答"你为什么这样感受/反应"，不适合直接断"事情一定会怎样"
3. **命理是结构解释，不是判决书** — 术语是为了说明互动机制，不是替代事实证据
4. **分层输出** — 每个结论标注确定性等级（高/中/低）

## 群体互动断法：比劫、官杀、印星三件套

遇到普通人际、合作、排队、分配、让步、合伙、同事竞争、群体沉默、责任分散等问题时，必须把十神翻译成群体互动机制，而不是只贴"比劫旺""官杀弱""印弱"的标签。

### 1）先判断现实场景是不是"有限资源 + 责任不清"

以下场景优先调用本断法：
- 电梯超重、座位/排队、公共空间、宿舍/办公室分工等低成本让步场景。
- 年终奖、股权、署名、项目功劳、岗位名额、晋升机会等利益分配场景。
- 多人合作中没人拍板、没人担责、没人愿意先退一步的僵局。
- 当事人反复表达"凭什么是我""为什么不是别人""我退了就是认输"。

如果不是有限资源、责任不清或同级竞争，而是亲密承诺、父母权力、职业平台制度，应分别转 `/bazi-qinmi`、`/bazi-jiating` 或 `/bazi-shiye`。

### 2）再看比劫是否成势

比劫在群体互动中代表同类、同级、竞争、比较、位置感和不服输。

比劫成势时，现实表现不是简单的"朋友多"或"有帮扶"，而是容易进入同级拉扯：
- 先问公平，再问效率。
- 先感到"我不能吃亏"，再考虑整体损失。
- 在同类面前不愿第一个让步，因为让步会被体验成认输、低位或被占便宜。
- 群体里每个人都等别人先动，局面容易从活棋变成死棋。

判断时要区分：
- **比劫有制**：竞争意识强，但能被规则、目标、责任或长远利益收束。
- **比劫无制**：谁也不服谁，彼此消耗，宁可一起拖住也不愿先退。
- **比劫得印化**：仍有竞争，但能因为共情、情分、共同体意识而主动让一步。
- **比劫被财牵**：竞争更容易落到资源、钱、机会、利益分配。

### 3）看官杀是否在场：规则、边界、拍板者

官杀在人际场里不是只代表职位或压力，也代表外部规则、边界、后果、监督、裁决和拍板能力。

比劫重的局，官杀能不能起作用，是判断僵局能否被打断的关键：
- **官杀在场且有力**：有制度、负责人、明确后果或权威裁决，同级竞争能被收束。
- **官杀缺位或虚浮**：规则没人执行，边界没人维护，每个人都把责任推给别人。
- **官杀太过**：能压住僵局，但可能带来恐惧、羞辱、强制、过度管控。
- **官杀被食伤冲破**：当事人知道规则，但容易顶规则、辩规则、绕规则。

输出时要翻译成现实语言：这里缺的不是"某个神煞"，而是清楚的规则、执行规则的人、违规成本，或能承担拍板责任的角色。

### 4）看印星是否能破局：同理、照顾、共同体半径

印星在人际场里代表理解、照顾、保护、教养、同理心、替别人多想一步，也代表一个人能不能把"别人的处境"纳入自己的决策。

比劫重而印弱时，常见表现：
- 只看见自己的损失，看不见别人被拖住的成本。
- 知道整体效率下降，但身体先保护自己的位置。
- 对近处、眼前、和自己有关的人会心软；对看不见的人、陌生人、抽象群体不敏感。

印星能起作用时，破局不一定靠外部压力，而是靠内部文明化能力：
- 愿意多等几分钟，换取整体顺畅。
- 能把别人的急迫当成真实存在，而不是背景噪音。
- 不把每一次让步都理解成输赢。

### 5）破局路径固定问两条

分析此类问题时，必须明确指出破局通常只有两类：
- **等官杀**：引入规则、负责人、排序标准、惩罚或明确边界。
- **等印星**：有人愿意共情、照顾大局、主动多走一步。

如果两者都没有，局面通常会拖到有人因羞耻、时间压力、旁观压力、现实代价而先破防。直播弹幕、围观评价、绩效考核、投诉机制等，都可以在现实中临时充当"官杀"。

### 6）写作边界

此断法只能用于解释结构机制，不能把性别、地域、职业、身份群体本质化。网络事件可以作为启发，但输出时必须去掉群体攻击，只保留结构：

> 比劫成势、官杀缺位、印星不显时，同级群体容易出现"没人愿意第一个让步"的僵局。

不要写成：

> 某类人天生不让步。

## 八步工作流

### 步骤 1：改写为现实命题

把用户问题翻译成现实语言。不要直接跳进十神/刑冲。

> 用户："她分手后还聊前任缺口不考虑我，是不是人生上也不会考虑我？"
> → 现实命题：**当她的需求与我的感受冲突时，我是否会被纳入她的决策模型？**

### 步骤 2：拆成命理子问题

从现实命题推导出命理层面需要回答的子问题。例如：
- 为什么此人对"被纳入共同体"如此重视？
- 为什么对"排序、位置、边界"特别敏感？
- 为什么同时表现高忠诚与强护界？
- 如果这是多人僵局：是比劫成势、官杀缺位，还是印星不足导致没人先让步？

### 步骤 3：确定检索节点

落到具体命理术语：日主气质、月令时令、十神结构、刑冲合会、透干根气、寒燥调候。若问题涉及同级竞争、合作僵局或责任分散，必须额外检查"比劫、官杀、印星三件套"。

### 步骤 4：检索古籍原文

**必须联网搜索原典，不凭记忆硬背。** 搜索模板和原典清单见 [references/classics-search.md](references/classics-search.md)。

> 🔍 **搜索工具**：优先使用 `dual-search` 技能（Perplexity + Tavily 并行），或 `mcporter call perplexity.search` / `mcporter call tavily.tavily_search`。备选：`searxng-search`、`exa-search`。

关键规则：
- 先搜精确句，确认原文存在
- 再搜上下文段落，不只截一句
- 再搜异议句，确认古人内部是否有不同看法

### 步骤 5：还原上下文

不断章取义。例如"庚金带煞，刚强为最"不能直接断"此人必刚猛"，还要看：
- 得水/得火/土润土干如何
- 什么季节、整盘寒燥强弱

### 步骤 6：结构化翻译

把古籍语言翻成可用的结构语言。翻译示例见 [references/translation-examples.md](references/translation-examples.md)。

核心要求：**不要简单贴标签，要翻成行为倾向描述。**

### 步骤 7：映射回现实

把结构语言重新对接用户的具体问题。例如：
- 忠诚需求高 → 容易认主、认承诺
- 边界防御高 → 被越界时迅速从依附切到护界
- 伤官透 → 感受锋利，容易把模糊升级为排序问题

### 步骤 8：分层输出

最终回答必须包含三层：

| 层级 | 内容 | 示例 |
|------|------|------|
| **现实层** | 这件事本身说明了什么 | "她的行为说明你目前不在她的核心决策圈内" |
| **命理层** | 为什么你对这类事反应特别强 | "日主庚金+比劫重，护界与位置感是底层驱动" |
| **边界层** | 哪些高把握，哪些只能推测 | "你的反应模式是高确定的；她未来行为是低确定的" |

## 证据优先级

1. **现实材料**（最高）— 用户叙述的事件、时间线、行为、承诺
2. **命理原典**（第一手）— 五部核心古籍原文
3. **学理比较**（第二手）— 门派分歧、不同解读
4. **现代语言重写**（最后）— 翻译为用户可用的结构语言

## 输出模板

```markdown
### 一、现实问题重述
把用户问题翻译成现实冲突。

### 二、命理拆解
列出相关的日主、月令、十神、结构张力。

### 三、古籍依据
1. 原文 A — 支持什么，不能支持什么
2. 原文 B — 支持什么，不能支持什么
3. 原文 C — 支持什么，不能支持什么

### 四、综合解释
把古籍语言翻译成用户能理解的结构解释。

### 五、落回现实
这套结构在现实中通常如何表现。

如果问题涉及多人僵局，追加：
- 比劫如何制造"凭什么是我"；
- 官杀是否提供规则、边界和拍板；
- 印星是否提供同理、照顾和主动让步；
- 现实破局更适合靠规则，还是靠共情。

### 六、结论分层
- **高把握**：…
- **中把握**：…
- **低把握/谨慎推测**：…
```

## 写作红线

### 不把八字写成判决书

- ❌ "你命里就是这样" / "她一定不会考虑你" / "你注定如何"
- ✅ "这套结构会让你更容易……" / "从命理语言看，你在这类情境中更可能……"

### 不把古籍写成鸡汤摘抄

每条引用必须回答：原义是什么？原书上下文说什么？适用于这个盘的哪部分？支持到哪一步？哪一步开始是现代推论？

### 不机械放大刑冲害合

看到刑，先问：
- 是不是全盘真正的核心矛盾？
- 有没有比刑更强的变量（月令、调候、病药、透干根气）？
- 古籍内部对刑有没有分歧？

### 补现实验证句

输出后补一句：如果这套解读是对的，现实里你大概率会出现哪些可观察表现？如果现实完全对不上，要回头修正，不硬套命理。

## 结论风格示例

✅ 好的：
- "你的盘更像高忠诚需求 + 高边界防御，不是前后矛盾，而是同一结构的两面。"
- "它解释的是你的反应模式，不等于自动证明对方的全部动机。"

❌ 不好的：
- "你就是恶犬命。"
- "寅巳刑，所以感情必坏。"
- "有伤官就一定嘴毒、婚姻差。"
