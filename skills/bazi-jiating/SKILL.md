# 八字家庭关系分析

## 目标

本模块专门处理家庭关系，不直接替代亲密、事业或健康专题。

重点回答：

1. 父母宫和早年家庭气候是什么。
2. 家中权力、资源、情绪和责任如何分布。
3. 命主从家庭里内化了什么关系模板。
4. 家庭责任、父母关系、家族牵连如何影响后续人生。
5. 哪些判断有命理证据，哪些必须靠现实反馈校验。

## 适用场景

- 用户问原生家庭、父母关系、家庭氛围。
- 用户问“我为什么总被家庭牵住”“家里谁更强势”。
- 用户问家庭责任、父母压力、家族资源或家族消耗。
- 亲密关系分析前，需要先单独拆家庭模板。
- 流年或大运触发父母、住处、家事、家庭冲突。

不优先用于：

- 单纯恋爱、伴侣、婚姻适配，转 `/bazi-qinmi`。
- 普通朋友、同事、合作、人际边界，转 `/bazi-renji`。
- 职业平台和岗位选择，转 `/bazi-shiye`。

## 前置要求

必须先有可读取的 `chart.md`。若没有排盘底稿，先转 `/bazi-dingpan`。

若用户问“家庭变动发生在哪几年”，先由本模块定家庭结构，再转 `/bazi-liunian` 做年份触发。

## 分析顺序

### 第1步：父母宫与早年气候

先看年柱：

- 年干十神。
- 年支十神与藏干。
- 年柱是否安宁、紧张、偏现实、偏控制、偏失序，还是偏漂浮。
- 年柱和月柱之间是否形成明显生克、冲合、刑害。

输出重点是早年气候，不直接断父母具体事件。

### 第2步：父母星与家庭角色

结合性别和命局结构看父母星、印星、财星、官杀等六亲线索。

重点不是机械断“父亲如何、母亲如何”，而是判断：

- 家里谁更像规则和压力来源。
- 谁更像供养、保护或控制来源。
- 家庭更重成绩、秩序、资源、情绪，还是现实生存。
- 命主在家庭中是被保护、被要求、被投射，还是过早承担。

### 第3步：家庭权力结构

观察：

- 官杀是否形成强规则和高压。
- 印星是否能提供稳定庇护。
- 财星是否让家庭关系偏资源、得失和现实交换。
- 比劫是否带来同辈竞争、兄弟姐妹、家族内比较或资源分割。
- 食伤是否让命主在家中更早表达、反抗、解释或承担情绪出口。

### 第4步：家庭模板内化

把命理结构翻译成现实语言：

- 爱是否容易和责任绑定。
- 靠近是否伴随压力。
- 家庭是否让命主熟悉高温、高压、冷处理或现实算计。
- 命主是否容易把家庭程序带进亲密、人际和事业选择。

### 第5步：大运流年触发

若问题涉及阶段变化，再看：

- 哪步大运激活父母宫、印星、财星或家庭责任。
- 哪些流年冲动年柱、月柱、父母星、住处和家庭宫位。
- 触发更像搬家、离家、父母压力、家庭冲突、家中角色变化，还是资源支持。

具体年份验证交给 `/bazi-liunian`。

## 输出要求

默认输出：

1. **家庭底色**：早年家庭气候和父母宫状态。
2. **家庭角色**：规则、供养、压力、资源和情绪由谁承担。
3. **内化模板**：命主从家庭里学会的关系程序。
4. **现实表现**：可能表现成的家庭责任、边界和牵连方式。
5. **边界**：哪些是结构判断，哪些需要现实反馈。

## 禁忌

- 不把父母宫一条信息直接断成父母具体职业、疾病或极端事件。
- 不把家庭模板直接等同于婚恋结论；婚恋要转 `/bazi-qinmi`。
- 不用姓名、头像、数字巧合做家庭判断。
- 不把已知现实伪装成盲断。
