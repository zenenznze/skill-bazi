# 八字流年与验盘

## 目标

当两套或多套候选命盘、用神假说或格局争议需要验证时，用前事和具体年份来验：

1. 哪张盘对人格、家庭、学业、恋爱和职业底色解释力更强。
2. 哪几年最容易出明显事件。
3. 每张盘在那些年份更可能应什么类型的事。
4. 最后哪张盘或哪套假说的时间线解释力更强。

这个模块只做一件事：
用前事解释力、年份和事件类型给候选盘或结构假说打分。

## 适用场景

- 用户说“根据过去年份帮我验证一下”
- 用户说“这张盘不对，能不能换另一张看看”
- 已有两套候选命盘，需要通过过往经历校验命盘
- 用户关心“到底哪张更像我或我朋友”
- 已有候选盘，但人物画像仍然都像一点
- 用户能回忆出几个明显年份
- 需要把“像不像”落到具体时间线
- 已有现成分析或名人案例年表，需要反证某套用神、格局或门派判断是否解释力更强

## 必要输入

1. 至少两套候选命盘
2. 当事人的基础现实信息，越多越好
3. 当事人可回忆的明显年份或年龄段
4. 至少一类现实事件

若不是候选盘验盘，而是已经有正式盘、用户问具体年份或月份，则必须有可读取的 `chart.md/chart.json`。没有底稿时先转 `/bazi-dingpan`，不能凭四柱文本直接断年份或月份。

若现实信息不足，可先输出待核问题清单。待核问题必须遵守 `references/momtest-validation-questions.md`，直接提问时改写成过去具体事件、原话、年份和可佐证记录，不问“你是不是……”。

高价值事件包括：

- 搬家、离家、住处变化
- 换学校、换班、换专业、升学波动
- 恋爱、暧昧、分手、拉扯
- 和父母、老师、上级冲突
- 受伤、炎症、摔碰、交通惊险
- 熬夜、失眠、低落、封闭
- 实习、工作、考证、方向焦虑

## 前事验证层

前事验证优先级：

1. 人格底色。
2. 家庭与父母气质。
3. 学历与专业方向。
4. 恋爱模式。
5. 明显年份事件。

候选盘之间的优劣，不看谁更玄，而看谁对现实有更强的解释力：

- 是否能解释长期气质。
- 是否能解释人生结构。
- 是否能解释关键年份事件。
- 是否能解释感情和家庭的真实感受。

分析阶段要把候选盘差异拉开，例如：

- A 盘：更闷、更扛、更现实、更慢热。
- B 盘：更锋利、更急、更反骨、更容易上头受伤。

但这些画像只能用于内部比较或已有事实后的解释，不能作为提问话术直接喂给当事人。

## 核心方法论

### 1. 年份验盘比泛泛性格更能拉开差距

当年、月相同，或者几张盘的人设都能讲通时，最有价值的不是继续堆性格词，而是看：

- 哪几年最容易动
- 动的是哪一类事
- 是外部事件，还是内部情绪

### 1.1 月份题必须生成流月底稿

当用户问到“某年某月”“今年 7 月”“几月份提交/面试/出行”“月内哪段更有利”时，先用年份判断确定该年在大运中的位置，再生成问真流月证据：

```bash
node scripts/pcbz_liuyue_fetch.mjs --year YYYY --chart-json path/to/chart.json --gregorian-month YYYY-MM --output path/to/chart-dir/liuyue-YYYY
```

只定位某一天时加：

```bash
--date "YYYY-MM-DD HH:mm:ss"
```

分析时必须读取生成的 `liuyue.md`，按节气边界切分公历月。不得把公历 7 月、8 月直接等同于单一流月；不得用本地 `lunar_python` 或手算流月替代问真前端 source map 逻辑。

### 2. 先抓最有区分度的年份，不要把每一年都讲一遍

优先找：

- 伏吟年
- 冲日支、冲时支、冲月令的年份
- 刑合明显、最容易落具体事件的年份

不要把所有年份平均用力。

### 3. 事件类型比细节故事更重要

先判断这一年更像：

- 住处与环境变化
- 感情与关系拉扯
- 学业与方向选择
- 权威与规则冲突
- 身体与压力问题

不要先把具体故事说死。

### 4. 年份验盘是打分题，不是文学题

每张盘都要给出：

1. 最该核的年份
2. 每年最可能应的事件类型
3. 命中就加分的验证点

### 5. 年表也可以反证用神假说

当争议点不是出生时辰，而是“到底用什么”时，先列出两个或多个结构假说，再用年表回看：

- 该假说的用神大运，是否真是核心上升期
- 该假说的忌神大运，是否真表现为受阻、耗损或代价加重
- 关键成就年是否由该假说解释得更自然
- 若某星只解释了表达、人设或局部收益，却解释不了职位、平台、出圈节点，就只能算成事工具，不宜直接升为全局用神

## SOP

### Step 1：先编号候选盘

例如：

- A 盘：……
- B 盘：……
- C 盘：……

后面统一按编号说，避免来回混乱。

若不是候选盘，而是用神/格局争议，则编号结构假说：

- A 假说：以某五行/十神为调候或病药核心
- B 假说：以另一五行/十神为调候或病药核心
- C 假说：某十神只是成事工具，不是全局用神

### Step 2：先看前事底色

优先比较：

- 压力下的反应方式。
- 学习轨迹是否稳定。
- 家庭中谁更强势、更操心。
- 感情是闷压型还是上头拉扯型。
- 专业和职业能力是偏理论、应用、系统、表达、技术还是事务。

如果一张盘在前事层已经明显更强，年份只作为加权，不用为了单一年份推翻整体底色。

### Step 3：再列出最值得核的 5 到 10 个年份

这些年份要能最大化区分候选盘，不追求多，只追求有效。

如果用户问题只关心某一年某月，不需要扩展成 5 到 10 个年份；改为列出该年主轴和该公历月内的流月分段。

### Step 4：逐年只说“最可能发生的事”

每年只回答三件事：

1. 哪张盘最敏感
2. 最可能应什么事件类型
3. 如果现实里中了，对哪张盘加分

如果在验证用神假说，每年回答：

1. 这一年引动了哪个结构
2. 更支持哪套假说
3. 这个事件是“长期受益”“短期显化”还是“带代价的成事”

若已进入流月层，每段只回答：

1. 这段流月从何时到何时。
2. 它引动的是原局、大运、流年中的哪一层。
3. 对用户现实问题是加速、缓冲、卡顿、竞争还是收尾。

### Step 5：给出每张盘的重点年份组合

例如：

- A 盘最该核：2013、2019、2025
- B 盘最该核：2020、2021、2023
- C 盘最该核：2016、2022、2025

### Step 6：给一个最简单的打分法

例如：

- 每中一条加 2 分
- 三个以上明显命中就可优先保留

### Step 7：最后才做收口

最终只回答：

- 最像哪张
- 次像哪张
- 为什么

## 可复用判断规则

### 规则 A：先看重年份，不看全年运势散文

年份验盘不是写流水账，而是抓关键节点。

### 规则 A1：月份题先切节气，不按自然月硬断

自然月经常跨两个流月。先引用 `liuyue.md` 的边界，再判断每段含义。

### 规则 B：先看事件类型，再看细节故事

例如先说“更容易搬家、住处变化、睡眠受影响”，不要一上来写成具体剧情。

### 规则 C：年份命中不能脱离人物底色

年份验证只能加权，不能完全推翻底色层和结构层。

### 规则 D：同一年不同盘要写出不同的应事风格

例如同样是敏感年：

- A 盘更像内耗、熬夜、关系变淡
- B 盘更像封闭、被困住、节奏被打乱
- C 盘更像冲突、拉扯、火气大、现实狠狠干

### 规则 E：不要用单一年份保护原判断

如果一套用神说法只在个别年份能解释，但在大运主线、职业平台、关键成就年上解释力弱，就要降级为“局部有效”。

反过来，如果另一套假说能连续解释多个节点，即使术语不如原说法漂亮，也应提高权重。

## 输出模板

### 模板 1：年份验盘开场

> 这次最适合用年份验盘法，因为这几张盘光看性格不够分胜负。真正能拉开差距的，是哪几年最容易出事，出的又是什么类型的事。

### 模板 2：逐年表达

> 2016 年：C 盘最敏感。
> 如果这张盘准，这年更容易出现冲突、受伤、分离、方向变化。
> 如果他对这年很有记忆点，C 盘加分。

### 模板 3：每盘重点年份组合

> A 盘最该核：……
> B 盘最该核：……
> C 盘最该核：……

### 模板 4：打分法

> 每中一条加 2 分。
> 哪张盘在关键年份里中得最多，哪张就优先保留。

### 模板 5：用神假说反证

> 这里不是验时辰，而是验两套用神说法。
> A 说法如果成立，最该在这些岁运见明显上升：……
> B 说法如果成立，关键事件应集中在这些岁运：……
> 现在年表显示：……，所以我会把 A 降级为局部成事工具，把 B 提升为主线解释。

## 导航协议

每次输出末尾必须补充以下四段，供 `/bazi` 主入口做任务后导航：

```markdown
## 核心结论
用 1-3 条概括哪张盘或哪套假说解释力更强，以及关键年份证据。

## 当前卡点
说明候选盘是否已经胜出；若没有，写明还缺哪些年份、事件类型或现实材料。

## 下一步线索
- 如果候选盘已收口，回到 `/bazi` 后建议转 `/bazi-geju` 或 `/bazi-mingju`。
- 如果仍需验盘，回到 `/bazi` 后建议继续 `/bazi-liunian`，并补充具体年份事实。
- 如果用户要把年份结论落到职业、关系或健康，回到 `/bazi` 后按主题分流。

## 不知道下一步用哪个 bazi 子技能？
输入 `/bazi`。它会根据刚才的结论推荐 2-3 个下一步。
```

## 错误清单

- 把年份验盘写成整年运势文章
- 每个年份都说一大堆，没有区分度
- 只说“有事”，不说事件类型
- 年份命中一点，就无视整体人物底色
- 为了维护原先用神结论，选择性解释年表
